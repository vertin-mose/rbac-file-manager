# RBAC Document Management System

## What was built
A full RBAC-based document management and collaboration system framework skeleton. Project located at `C:\Users\华硕\Desktop\实验\rbac-file-manager\`.

**Tech stack:** Spring Boot 3 + Java 17 + Spring Security 6 + JPA + Vue 3 + TypeScript + Element Plus + MySQL/PostgreSQL + Redis + MinIO + Docker Compose.

**Why:** Software security course project at university.

## Role system (6 roles with hierarchy)
- SUPER_ADMIN > ADMIN > MANAGER > EDITOR + REVIEWER > VIEWER
- Hierarchy stored in `role_hierarchy` table, resolved recursively at runtime
- Higher roles inherit all permissions of lower roles (RBAC-1 model)
